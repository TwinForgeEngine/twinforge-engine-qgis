description=Publish QGIS layers to TwinForge Engine and add TwinForge Engine layers to QGIS, using a TwinForge Engine access token.
about=Connect with a tft_ access token from your TwinForge Engine account (Account, API keys) that has gis:read, and gis:publish if you want to publish. Choose a project, tick vector or raster layers and publish them to the TwinForge Engine PostGIS workspace. Classes, colours, legend, labels and pop-up fields travel with each vector layer; rasters are converted to Cloud Optimized GeoTIFF on your computer before upload. Published layers can then be added in TwinForge Map, in a TwinForge Engine scene and in TwinForge Canvas dashboards. Layers that are already in TwinForge Engine can be added back into QGIS. The token is kept in the QGIS authentication database, never in project files. Interface in English, Thai and Japanese. Requires a TwinForge Engine account (https://twinforgeengine.online).
